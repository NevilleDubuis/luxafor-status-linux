luxafor-status

apt repository · latest: @VERSION@

Control a Luxafor status light from Ubuntu or Debian. Install it once and get updates with the rest of your system:

curl -fsSL @URL@/key.asc | sudo gpg --dearmor -o /usr/share/keyrings/luxafor-status.gpg
echo "deb [signed-by=/usr/share/keyrings/luxafor-status.gpg] @URL@ stable main" \
  | sudo tee /etc/apt/sources.list.d/luxafor-status.list
sudo apt update
sudo apt install luxafor-status

For pre-releases, use testing instead of stable.
